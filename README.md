# bear.ski
This is my website! I made it using Angular, Bootstrap, SASS, Node.js and TypeScript. It's run on my own RasPi server with Docker Compose.

## Deploy
If you want to run this on your own system it's as easy as running the following.
```bash
git clone https://github.com/skistaddy/bear.ski.git
cd bear.ski
sudo docker compose up -d --build
```
